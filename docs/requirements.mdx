title: "Requirements"
description: "What must be on the machine before installing Jig UI."
---

- **Node.js.** Jig UI runs on Node.js, and Node.js must already be installed — Jig UI does not
  bundle it. The minimum version is set when the stack is fixed. The installer checks this
  before it installs anything.
- **git.**
- **Jig**, in each project you connect.
