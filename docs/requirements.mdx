---
title: "Requirements"
description: "What must be on the machine before installing Jig UI."
---

- **Node.js 24 or later.** Jig UI runs on Node.js and is started with `npx`, which comes with Node.js.
  Without Node.js, [one line](/installation#without-nodejs) puts Node.js in Jig UI's own folder,
  with nothing installed system-wide.
- **git.**
- **Jig 0.31.0 or later**, in each project you connect. Older versions are shown as such and not read;
  `jig upgrade` in the project brings it up to date. Marking a project to upgrade and upgrading it
  from the page need Jig 0.34.0 or later; resuming a paused task from the board needs 0.35.0;
  **Check merge** on an upgrade that waits for its pull request, and a task's documents on its full
  details page, need 0.39.0.
