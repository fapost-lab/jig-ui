Stable releases run with `npx @fapost/jig-ui`; what is under **Unreleased** is on the
[development channel](/installation#development-channel) and comes with the next release.

## Unreleased

- [Projects to upgrade](/projects#what-the-page-shows): a project whose Jig is older than the one on
  this machine shows both versions, and a line above the projects counts them. The project's Jig
  reports it from 0.34.0 on.

- [Resume a paused task](/projects#resuming-a-task) from the board: drag it out of Paused onto the
  column it will be in, or choose **Resume** in its ⋯ menu. Jig UI runs `jig task resume` with the
  revision of the board you saw; a pause whose stash cannot be applied says what to do instead.
  Needs Jig 0.35.0 or later in the project; with an older Jig the card names the command as before.

## 0.3.0 — 2026-10-25

The board changes things now, always through Jig's own commands.

- [Order the work](/projects#ordering-the-work) from the board: drag a card within its column, or
  use its ⋯ menu, to move it in the project's queue; set its priority from P0 to P5. Every change
  goes through `jig queue`, and a change the project overtook is refused and the board read again.
- A change the project overtook shows the [conflict](/projects#ordering-the-work): the line above
  the board says what became of your card, and the cards that changed while you acted are marked.
- [Pause a task](/projects#pausing-a-task) from the board: drag it onto Paused, or use its ⋯ menu,
  to ask Jig to pause it at its next stage boundary; the card shows the request with its age and a
  cancel. A paused card names the command that resumes it.
- [File a task](/projects#filing-a-task) from the board: **New task** takes an id and a goal and
  runs `jig task new`; the task appears in Backlog.
- The count of finished tasks above the board opens [the list of them](/projects#the-board) Jig
  still keeps, with each one's status, goal and pull request; it starts hidden.
- A project that cannot be read shows a red `!` on its tab.
- Jig UI now needs Jig 0.31.0 or later in each project; run `jig upgrade` in an older one.

## 0.2.0 — 2026-10-22

- A board opens faster: each project is read once when the page opens, not twice.
- An error Jig UI did not foresee is reported on the page as an internal error.
- A `projects.json`, `instance.json` or an answer from another running Jig UI that is not what it
  should be is refused rather than shown as it is.
- Every answer of the server carries security headers.

## 0.1.0 — 2026-10-18

The first release.

- `npx @fapost/jig-ui` starts Jig UI on `127.0.0.1:4870` and opens it in the browser; run in a Jig
  project's folder, it connects that project. A second run opens the running one.
- [Connect and disconnect projects](/projects); the list is kept in your config directory.
- Every connected project's tasks on one page, and each project's board, in columns or as a list.
- Specs with their phases and roadmap progress.
- A task's details open from its card.
- The page follows connected projects as they change, without a reload.
- `--port` and `--no-open`.
