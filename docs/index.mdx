---
title: "Jig UI"
description: "A local control center for Jig projects."
---

Jig UI is an optional local application on top of [Jig](https://github.com/fapost-lab/jig). One
page shows every task and epic of every connected project, so a person running several agents
across several projects sees what is running, what waits for them and in what order work goes.

Jig works exactly as before without it: task files and artifacts stay the source of truth, and
every change Jig UI makes goes through Jig's own commands.

<Note>
Jig UI is in early development. These pages describe what is planned and will grow as it is built.
</Note>
