---
title: "Requirements"
description: "What must be on the machine before installing Jig UI."
---

- **Node.js 24 or later.** Jig UI runs on Node.js, and Node.js must already be installed — Jig UI does not
  bundle it. Jig UI is started with `npx`, which comes with Node.js.
- **git.**
- **Jig**, in each project you connect.
